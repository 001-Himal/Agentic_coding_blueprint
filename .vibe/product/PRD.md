# PRD.md

> ⏳ To be created by the AI during the FIRST planning session, specific to the actual project.
> Do NOT pre-fill with generic content. This becomes the single source of truth for WHAT/WHY.

It should typically contain (shape adapts to the project):
- Overview / one-liner / vision
- Problem & why now
- Goals + success metrics
- Non-goals (anti-scope)
- Users / personas
- Core user flows
- Requirements: functional (FR-xxx) and non-functional
- Acceptance criteria (AC-xxx)
- Constraints & dependencies
- Open questions

Once created, every FEAT/TASK/ADR links back here.
