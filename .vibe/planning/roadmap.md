# roadmap.md

> ⏳ To be created by the AI during the FIRST planning session, specific to the actual project.
> Phasing, number of phases, and scope are decided at planning time based on the project.
> Do NOT hardcode phases here.

When the AI creates it, require a PHASEWISE-DETAILED structure, e.g.:

## Phase 1 — <name, e.g. Foundation / MVP>
- Goal:
- Scope (in/out):
- Deliverables:
- Exit criteria (must all pass before moving on):
- Linked FEAT/TASK IDs:

## Phase 2 — ...
(repeat; number of phases depends on the project — could be MVP → Core → Polish → Growth, could be anything)

## Later / Icebox
- Ideas not committed to a phase

Rules once created:
- Never start a later phase while the current phase's exit criteria are unmet (unless human re-prioritizes).
- Phase changes require updating `planning/milestones.md` and `planning/current.md` in the same change.
- Every phase maps to PRD goals.
