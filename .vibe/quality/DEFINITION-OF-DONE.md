# DEFINITION-OF-DONE.md

A task is done only when ALL are true:

- [ ] Requirements satisfied
- [ ] Scope respected
- [ ] Existing functionality preserved
- [ ] Code modular
- [ ] No unnecessary abstraction
- [ ] No duplicate logic
- [ ] No dead code
- [ ] No unexplained dependency
- [ ] Tests pass
- [ ] Typecheck passes
- [ ] Lint passes
- [ ] Security checked
- [ ] UI checked where relevant
- [ ] No tech stack or infrastructure leaked into UI copy / user-facing text
- [ ] Accessibility checked where relevant
- [ ] Documentation updated
- [ ] Diff reviewed
- [ ] No unresolved TODOs
- [ ] No fake/mock implementation
- [ ] No known regression
