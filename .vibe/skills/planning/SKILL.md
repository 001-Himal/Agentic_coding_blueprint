# Skill: planning
1. Read spec + context docs.
2. Confirm PRD (`product/PRD.md`) and phasewise roadmap (`planning/roadmap.md`) exist; if missing, create them first — project-specific, single source of truth for PRD, phasewise detailed roadmap with phases decided by the project.
3. Inspect existing code.
4. Produce plan: assumptions, files to change/NOT change, steps, risks, open questions.
5. Stop. Wait for human approval.
