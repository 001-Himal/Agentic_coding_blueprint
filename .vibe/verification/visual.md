# visual.md

Check UI at: desktop, tablet, mobile, loading, empty, error, long content, slow network, dark/light if supported.
Copy audit: ensure no tech stack, infrastructure, or protocol details leak into user-facing text.
Color audit: verify every text/bg pairing passes WCAG AA in both themes, all interactive states, badges, toasts, and text over images/overlays (no washed-out pastels, gray-on-gray, or unmeasured white-on-brand).
